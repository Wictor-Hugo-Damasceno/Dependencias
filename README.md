# Créditos e Licenças de Terceiros

Este projeto utiliza bibliotecas e ferramentas de código aberto. Abaixo estão os créditos e links para os respectivos projetos e suas licenças.

## 1. Raylib
Este projeto utiliza a biblioteca **raylib** para a interface gráfica e funcionalidades de desenho.
* **Site oficial e Repositório:** [https://www.raylib.com](https://www.raylib.com)(https://github.com/raysan5/raylib)
* **Licença:** raylib é licenciada sob a **Licença zlib**, que permite o uso gratuito, modificação e redistribuição.

## 2. w64devkit (GCC)
O ambiente de compilação utilizado para este projeto portátil é baseado no **w64devkit**.
* **Desenvolvedor:** Chris Wellons (skeeto)
* **Link oficial:** [https://github.com/skeeto/w64devkit/releases](https://github.com/skeeto/w64devkit/releases)
* **Licenças:** Os componentes (GCC, GNU Make, etc.) são distribuídos sob licenças de código aberto como a **GPL**.
